SRI NEWS FIXED

Changes:
1. Home Read feed now shows exactly one news card per vertical page; swipe/scroll vertically for the next news.
2. News images are no longer loaded/uploaded. The built-in BREAKING NEWS visual is used instead.
3. Reporter posting no longer uses Firebase Storage or image picker.
4. Owner page now has a visible "Post News" option and can publish news directly to Firestore.
5. Owner post form includes category, title, content and Breaking News toggle.
6. Firestore owner access accepts either the admin custom claim or users/{uid}.role == owner.

Firebase Storage is therefore not required for posting in this version.
