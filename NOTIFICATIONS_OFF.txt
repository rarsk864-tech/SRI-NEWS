OFF-APP / TERMINATED NOTIFICATION SETUP

The app is configured for Firebase Cloud Messaging.

When the app is closed/backgrounded/terminated, Android displays an FCM
notification automatically only when the sender sends a notification payload
(or a notification + data payload). The mobile app cannot reliably create a
notification after it has been killed.

Topic:
  all_news

Use Firebase Console -> Messaging -> create/send notification -> target
the all_news topic.

For automatic notifications whenever Owner publishes a news item, use a
trusted backend/Cloud Function that sends an FCM notification to topic
all_news. Do not put server credentials in the APK.
