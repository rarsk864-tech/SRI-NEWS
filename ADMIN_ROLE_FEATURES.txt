SRI NEWS ADMIN / OWNER ROLE FEATURES

OWNER
- Owner is a separate role.
- Owner sees Users, Reporters, Admins and Owners separately.
- Owner can make a normal User an Admin.
- Owner can remove Admin access and return the account to User.
- Owner can approve/reject reporter applications.
- Owner can approve/reject reporter posts.
- Owner retains full news management controls.

ADMIN
- Admin is a separate role from Owner.
- Admin can open Admin Dashboard from Account.
- Admin can approve or reject pending Reporter Posts.
- Approved Reporter Posts are published to the news collection with approvedByRole=admin.
- Admin cannot manage users/admin roles.
- Admin cannot use Owner Dashboard.

USER VISIBILITY
- Account profile shows OWNER / ADMIN / REPORTER / USER role.
- When Owner changes a user's role, the user's Firestore profile updates live, so the Account screen shows ADMIN and Admin Dashboard automatically.
